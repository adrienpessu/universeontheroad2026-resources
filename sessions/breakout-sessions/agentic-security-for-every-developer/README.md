## 1. Learn the presentation

1. Read the slides and speaker notes from start to finish.
2. Review the presenter guide for key messages and slide-specific talking points.
3. Practice the presentation aloud, including transitions into and out of the demo.

## 2. Deliver the talk

Use the [presenter guide](speaker-resources/presenter-guide.md) for the full talk track. Keep to the planned timing and switch to the demo backup if needed.

## 3. Reproduce the demo

Use the [demo repository GitHub](https://github.com/octodemo/agentic-security-for-every-developer) or [demo repository Microsoft](https://github.com/msft-common-demos/agentic-security-for-every-developer), prepare with in and run the demo end-to-end before presenting. Confirm the expected result and that the backup works.

## Final checklist

- [ ] Slides and speaker notes reviewed.
- [ ] Talk rehearsed and timing confirmed.
- [ ] Demo setup and walkthrough tested.
- [ ] Backup ready and resource links checked.
